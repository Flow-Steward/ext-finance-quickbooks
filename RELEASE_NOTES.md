# QuickBooks Online 1.0.0

Native Python QuickBooks Online accounting extension for Flow Steward.

- 145 operations: all 142 tools from the pinned official Intuit MCP server, plus three convenience operations.
- 12 financial reports; customers, invoices, bills, payments, PDFs and attachments.
- OAuth 2.0 managed by Flow Steward; extension host v2 and public SDK 0.4.0.
- One portable ZIP for Linux AMD64 and ARM64; no Node.js runtime required.
- Uses the standard Flow Steward extension icon.

Configure an Intuit OAuth application, connect QuickBooks and set the company realm ID in Flow Steward before use.

Live Intuit authorization and installation on both architectures have not been verified.
